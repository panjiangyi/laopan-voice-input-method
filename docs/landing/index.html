03 / ARCHITECTURE

一条管线，按住说话 → 上屏。

实时优先保证"边说边有字"，松键后再花几百毫秒补标点、纠错、提交。一次听写是独立的 ASR stream / recorder，异常不会污染下一次。

05 / INSTALL

Ubuntu 24.04 · 一条 deploy.sh。

依赖一次性装好，之后每天一行命令就能更新。 

# 依赖和模型已经装好时，日常更新直接：
./deploy.sh
# 默认开启 DeepSeek 标点纠错；模式默认 punctuation（只补标点 / 空格）
# 关闭 AI：
VOICEIME_LLM_ENABLED=0 ./deploy.sh
# 1. 构建 Fcitx5 原生桥
sudo apt-get install -y g++ libfcitx5core-dev libfcitx5utils-dev libfcitx5config-dev
bash native/build.sh && bash native/install.sh && fcitx5 -r

# 2. 中英双语实时识别后端
bash scripts/09-setup-sherpa.sh

# 3. （可选）松键后二遍纠错模型，默认关闭
bash scripts/11-setup-quality.sh

# 4. DeepSeek 后处理：项目根 .env，权限 600
cat > .env <<'EOF'
DEEPSEEK_API_KEY='...'
DEEPSEEK_BASE_URL='https://api.deepseek.com/anthropic'
DEEPSEEK_MODEL='deepseek-v4-flash'
EOF
chmod 600 .env

# 5. 启动用户级 systemd 服务
bash scripts/10-install-service.sh
# 当前状态 / 进程 / 麦克风
./voiceime-status

# 实时日志
journalctl --user -u voiceime-ptt -f
journalctl --user -u voiceime-corrector -f

# 出问题时一键清理
./voiceime-reset

# 跑同一批真人样本做 A/B
python3 scripts/08-offline-suite.py \
  --manifest samples/voice-input-session-*/manifest.tsv
